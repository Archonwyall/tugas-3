# Portofolio Nawal anggara putra

Website portofolio pribadi yang saya buat di Kelas Industri UBIG (Paket 3, Minggu 01 sampai 05).
Website ini tampil rapi di ponsel, tablet, dan laptop.

- Website: https://nawal-tugas3.vercel.app

## Tampilan

![Tampilan beranda portofolio](img/tampilan-portofolio.png)

## Fitur

- Halaman **Beranda** berisi profil, dan pencapaian saya
- Halaman **Proyek** berisi daftar proyek dalam bentuk kartu
- Halaman **Kontak** berisi form untuk menghubungi saya
- Tampilan responsif dengan Flexbox dan *media query* serta menambahkan js
